# CyberArk PAM-DEF Trainer

**Live app: https://keyfive5.github.io/pam-def-trainer/**

Free practice app for the CyberArk Defender - PAM (PAM-DEF) certification exam.

- 236 practice questions across 10 topics, each with an explanation
- Quick Quiz, Smart Review (spaced repetition), 90-minute Exam Simulator, Full Marathon, Browse & Cram
- Optional free sign-in to sync progress across devices

*This repository hosts the published site. Community study tool — not affiliated with or endorsed by CyberArk.*
